## 結論

Windows 筆電鎖定後若黑屏無法喚醒，可先關閉「快速啟動」與「PCIe 連結狀態電源管理」，目前實測可恢復正常。

## 適合用在哪裡

- 鎖定螢幕或待機後，畫面無法再次亮起。
- 鍵盤、滑鼠仍可能有反應，但只能強制重新開機。
- Windows 筆電出現不固定的休眠或喚醒異常。
- 想先從系統電源設定排除問題，不立即重灌或送修。
## 流程步驟

### 1. 關閉 Windows 快速啟動

快速啟動會保留部分系統狀態，加快下次開機速度，但有時可能干擾休眠、關機與硬體重新初始化。

- 按下 `Win + R`，輸入 `control` 開啟控制台。
- 將「檢視方式」切換為「大圖示」。
- 進入「電源選項」。
- 點擊「選擇按下電源按鈕時的行為」。
- 點擊「變更目前無法使用的設定」。
- 取消勾選「開啟快速啟動（建議選項）」。
- 儲存變更後重新開機。
這個設定通常是優先排查項目。若問題來自關機狀態或驅動程式沒有完整重新載入，關閉後可能改善喚醒失敗。

### 2. 關閉 PCIe 連結狀態電源管理

PCIe 連結狀態電源管理會降低顯示卡或其他 PCIe 裝置的耗電，但部分硬體可能無法從深度省電狀態正常恢復。

- 進入控制台的「電源選項」。
- 在目前使用的電源計畫旁，點擊「變更計畫設定」。
- 點擊「變更進階電源設定」。
- 展開「PCI Express」。
- 展開「連結狀態電源管理」。
- 將設定調整為「關閉」。
- 點擊「套用」並確認。
若筆電分成「使用電池」與「一般電源」兩個選項，建議先全部設為關閉，再觀察黑屏問題是否仍會發生。

## 補充

- 關閉 PCIe 省電可能稍微增加耗電量，確認問題解決後，可再測試只關閉插電模式。
- 修改設定後務必重新開機，避免舊的電源狀態仍被保留。
- 若問題持續，下一步應檢查顯示卡驅動程式、BIOS 與 Windows 更新，不要一直靠強制關機硬扛。

## 收尾

先關閉快速啟動，再停用 PCIe 連結狀態電源管理，是排查 Windows 鎖定黑屏問題成本最低的做法；若仍無效，再往驅動程式與 BIOS 查，莫與黑屏鬥法到天明。
